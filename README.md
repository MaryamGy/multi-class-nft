Multi-Class-NFT
A SIP-009 compliant NFT contract with multiple rarity classes, built with Clarity on the Stacks blockchain.
It enables minting and managing NFTs across different classes such as common, rare, epic, legendary.

Features
Mint NFTs across multiple classes
Class-based rarity system for NFTs
SIP-009 standard compliant
Metadata includes rarity class
Transparent minting and transfers

Technical Overview
Language: Clarity
Standard: SIP-009 (Non-Fungible Tokens)
Core Functions:
mint – create NFT in specified class
transfer – send NFT to another address
get-owner – check current owner

get-class – retrieve class of NFT

get-last-token-id – view last minted ID
